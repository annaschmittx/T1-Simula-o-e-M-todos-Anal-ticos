Arquivos necessários:
main.cpp
model.yml

Importante: instalar o leitor yaml-cpp
No Linux: sudo apt-get install libyaml-cpp-dev
No macOS: brew install yaml-cpp

Passos:
1. Abra o terminal
2. Vá para a pasta onde estão salvos os arquivos
3. Compile o código (usando o yaml):
g++ main.cpp -o simulador -lyaml-cpp
4. Execute a simulação:
./simulador
